# Code of conduct

## The short version

Be decent. Assume the person you're replying to is acting in good faith and
knows things you don't. Critique code, not people.

## Not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption, or
publishing anyone's private information.

## Scope

Applies in issues, pull requests, discussions and any other space representing
this project.

## Enforcement

Report a problem by opening a
[private security advisory](https://github.com/pa/flow-bar/security/advisories/new)
(it's the only private channel this repo has) or by contacting the maintainer
through GitHub. Reports are handled confidentially. Maintainers may edit or
remove contributions, and may block accounts, when this policy is breached.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
